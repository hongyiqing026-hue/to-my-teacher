# ✉️ 教师节互动电子信封 (Teacher's Day Interactive Letter)

> 一份采用米白与复古暖色调设计的 H5 电子信封网页。包含了火漆印章拆封、信纸抽出动画以及打字机逐字显示效果，适合生成网页链接后直接发给老师。

---

## 🌿 项目特色

* 🎨 **复古暖色调**：米白背景与质感信纸设计，温馨浪漫。
* 💌 **火漆印章拆封动画**：点击信封触发盖子翻转与火漆拆封效果。
* 📜 **信纸抽出效果**：信纸平滑升起，并伴随流畅的打字机逐字显现效果。
* 🎵 **背景音乐支持**：内置轻柔背景音乐与旋转播放按钮。
* 📱 **移动端全适配**：针对手机与微信内置浏览器优化，体验自然。
